# Trevor Malone Portfolio

This is the personal portfolio website for Trevor Malone, Software and AI Engineer. It showcases professional background, featured projects, technical skills, and provides a contact form for direct communication.

## Features
- Modern, responsive React + Vite frontend
- About, Projects, and Contact sections
- Animated UI with Tailwind CSS
- Dynamic contact form that sends messages directly to Trevor Malone's email

## What technologies are used for this project?

This project is built with:

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
